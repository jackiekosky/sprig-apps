# sprig apps

Downloads for [sprig](https://sprig-list.vercel.app), a calm to do list that stays in sync everywhere.

- **sprig for mac**: the app, a menu bar list and a desktop widget. macOS 26 or newer. Unzip, drag sprig to Applications, then right click and choose Open the first time.
- **sprig for windows**: the app and a tray list by the clock. Windows 10 or 11. If Windows warns you, click More info, then Run anyway.

Get them from the [latest release](https://github.com/jackiekosky/sprig-apps/releases/latest). Sign in with your sprig account.

Grown by [jackays.dev](https://jmarie-dev-ochre.vercel.app).
